# Cynthia Owolabi

**Senior Full Stack Engineer**

I’m Cynthia. I build web applications and the services behind them. Much of my work has been in payments, where a failed request can leave someone waiting to find out what happened to their money. I’ve also worked on cloud infrastructure and AI support tools.

### Work

At **Duplo**, I build internal administration software and payment integrations. That includes Xero accounting sync and Wema Bank payouts, along with the access controls and approval steps used by operations teams.

At **Bitso**, I worked on an LLM customer-support assistant and transaction risk analysis. Before that, I built distributed applications at **Microsoft**, where automated processing cut API scan completion from **15 hours to 5 hours**.

My infrastructure work includes artifact distribution and AWS migration at **Indeed**. At **Interswitch**, I built transport software and helped move services off an Enterprise Service Bus. Uptime increased from **88% to 99.7%** during that work.
